## IndexTTS 2.5 接入审查（2026-11-03）

语音合成、音色管理和 WebUI 切换到独立 IndexTTS HTTP 服务。审查修正了实际推理入口仍使用 2.0、构造参数错误、未加载 QwenEmotion、遗漏必传语言和启动脚本误用 MyBot Python 环境的问题。独立服务使用上游 Python 3.10/3.11 环境，Ruff 对该目录单独使用 Python 3.10 目标，防止格式化引入 3.14 专属语法；半精度改为 2.5 使用的 BF16，默认 FP32。

- Ruff、格式检查、compileall、basedpyright（零错误、零警告）、TypeScript 和 Vite 生产构建通过。完整测试 332 项通过，6 项环境相关测试跳过；独立服务另用 Python 3.11 编译检查。
- 14 项 TTS 测试覆盖固定主音色、四种情绪载荷、语言、WAV/PCM、重试、权限与取消、音色上传删除、配置保真和错误脱敏。新增的推理适配测试用保持上游必要参数的模型替身，走真实服务端和 `IndexTTSEngine`，能发现错误导入、构造和推理参数。另用实际 ffmpeg 验证浮点 WAV 上传后可读取为 PCM；未安装 ffmpeg 的环境跳过该转换测试。直接 HTTP 请求拒绝非法向量及互斥情绪组合，不回显原始输入；推理过程不输出上游的情绪内容。
- 临时配置及模拟推理服务下，浏览器验证模型加载/卸载、上传、试听原声、选定音色自动写回、当前音色删除保护、删除确认与 Esc、四种情绪试听和语言传递；Ctrl+K/Ctrl+S、冲突继续编辑/覆盖保留外部字段/放弃加载外部版本均通过。亮暗主题在 1600px、375px 下无横向溢出、无脚本错误；两次 HTTP 409 来自主动注入的配置冲突。
- 仓库 Dockerfile 的完整镜像构建通过，镜像内示例配置可加载，包含 WebUI 产物。

真实推理使用官方代码 `d9e41aac89fd00b3d71497fddb287b7f24613712`、IndexTTS-2.5 权重 `c39ce5ba981572cb187443877ff559dfb246ce63`、Python 3.11.13、PyTorch 2.8.0+cu128，在 RTX 2080 Ti 上以 FP32 执行。官方 2.44 秒浮点 WAV 通过实际 ffmpeg 转换后入库；加载耗时 37.53 秒，reference/text/vector/audio 四种模式分别在 10.62/8.06/3.55/3.33 秒生成有效的 22.05 kHz、16-bit WAV，时长 2.59～2.95 秒，均非静音。合成后模型分配显存 7960 MiB、缓存预留 8512 MiB。这是同一短句的功能实测，包含首次运行开销，不作为性能基准或主观音质评价；未向 QQ 发送语音。

旧 Gemini 配置需按 [接入说明](../deploy/indextts/README.md)逐项调整，不能直接套用新镜像或覆盖独立运行配置。

经用户授权，在同一测试群、同一原镜像、同一张 128×128 RGB PNG 上对照：重建且保留原代理仍在 60 秒后超时；确认关闭 QQ 代理并在线后，1.83 秒取得成功回执与消息 ID。临时配置在测试后恢复并核对原值。这定位到当前 QQ 经 SOCKS 代理的媒体发送路径，不代表图片过大或 MyBot 拦截，也不能把所有代理软件或所有 NapCat 版本概括为同一问题。

应用层同步修正两处独立问题：只有明确的 `sendMsg` / `onMsgInfoListUpdate` 成功确认超时才标为结果未知，其他 NapCat 错误保持原错误语义；只有本次请求确有成功的前序回执时才提示不要重发前序部分。未确认的相同请求沿现有未知动作记录防止重复提交，取消、权限和发送额度检查保持执行。
