# 正常使用与失败恢复调整

本次按独立行为处理审计中的 20 项问题，并调整 8 类运行限制。权限、目标归属、取消检查、凭据隔离、工作区边界和配置乐观锁继续生效。

## 20 项对应结果

| 项目 | 当前行为 |
| --- | --- |
| 1. 工具结果固定字符截断 | 删除 `tool_result_char_limit`；完整结果进入统一上下文预算，不切 JSON、分页标记或回执。 |
| 2. 80% 提前硬停 | 80% 只触发压缩；失败且仍低于完整窗口时继续，超出实际配置窗口才必须缩小或停止。 |
| 3. 未知动作无法解除 | 控制台可核实为已执行/未执行，解除指定记录，不自动重放；后续调用仍检查当前权限。 |
| 4. MCP 只读分类 | 本地 `effect_tools` 优先，其次本地 `read_only_tools` 和服务 `readOnlyHint`；分类不授予权限。 |
| 5. 单次 MCP 失败连带断开 | 参数错误和单次超时保留连接；真实连接失效才撤下服务并重连。 |
| 6. 一个坏工具使目录全失效 | 单独排除不支持的名称/schema，控制台列明原因；其他工具仍可用。刷新失败保留上一份目录。 |
| 7. 准备失败扣发送额度 | 引用与媒体准备不扣额度，只在提交发送时计数；确认未提交时回退计数。 |
| 8. 未知发送阻止其他内容 | 只拦截相同参数和目标的未知动作；不同内容可以继续发送。 |
| 9. 全体艾特规则误伤非 QQ 数据 | 检查限定在 QQ 发送工具。 |
| 10. 第 21 项媒体不可读 | 先按显式索引选取，或用 offset/limit 分页；返回总数、下一页和原始索引。 |
| 11. URL 耗尽全部回退时间 | 每次下载/刷新独立使用媒体超时，失败后仍尝试 NapCat 刷新与流式下载。 |
| 12. 动作超时覆盖媒体超时 | 调用显式指定的超时直接生效。 |
| 13. 转发固定裁切 | 外层节点分页；按返回的 forward_paths 读取嵌套层；仅拒绝循环和不属于当前消息的路径。 |
| 14. 大文本整份拒读 | UTF-8 文本按字节游标连续读取，写入支持追加；修改已有文件仍受 overwrite 策略约束。 |
| 15. 目录只显示 1000 项 | 返回 total/next_offset，模型与 WebUI 均能继续翻页。 |
| 16. 固定 5 秒丢日志尾部 | 使用命令剩余时限收尾；回执标明输出完整性。超过预览预算的完整输出写入工作区并返回路径。 |
| 17. 沙箱检查失败隐藏文件管理 | 执行状态与文件管理分开；隔离/配额异常仍可查看与清理文件。 |
| 18. 自动保存失败不恢复 | 临时网络和服务错误退避重试，冲突与字段错误仍要求处理；回执丢失但内容已写入时识别成功。 |
| 19. 文件名含两点被误拒 | 按路径分段识别父目录引用，允许合法文件名中的连续点。 |
| 20. 错误信息过度泛化 | 保留安全的协议错误类别、校验位置、文件错误码与异常栈位置，不回显参数值、正文或密钥。 |

没有发送的轮次另外标为“未发送消息”，不会把普通模型输出作为 QQ 回执或异常兜底消息发送。

## 8 类运行限制

1. **闲时压缩**：新消息到达即中断压缩，原文保留。
2. **工具发现与加载**：发现支持自行选择页大小；删除每批 12 个限制。可替换已加载集合；已知且获授权的工具可直接调用；加载回执不重复 schema。
3. **轮次与发送预算**：正常模型请求与压缩分开计数，各使用配置额度；保留整轮时间预算。删除配置值上的任意最大值，实际发送按提交次数计数。
4. **队列与会话容量**：接入队列、等待队列、保留会话数与字节预算可配置；概览显示丢弃/拒收计数，回收仍有活动记录。
5. **QQ 字段限制**：去掉本地额外的文本、数组和查询数量上限，保留必填、类型、范围归属与协议枚举。实际平台接受程度由 NapCat 回执说明，群策略仍可设置参数限额。
6. **文件、媒体和输出预算**：媒体预算保持可配置；工作区传输统一使用 transfer_max_bytes；文本与目录分页，输出溢出有完整文件；配置编辑预算改为可配置。
7. **工作区互斥**：仍保证文件边界检查时没有执行容器改路径；执行和文件操作在有界内存中等待锁，排队执行可取消。等待容量由 max_pending_operations 配置，满时明确返回未执行，避免引入无界队列。删除清理仍要求执行结束或停止后确认。
8. **网络出口**：公网 IPv4/IPv6 候选逐个尝试；允许端口和并发可配置；固定总时限改为空闲时限。私网、宿主和绕代理直连仍被阻止。

QQ 上限核对基于锁定的 NapCat `859eb530c5801577633c2c3ae871d23586edf281`，例如 [历史查询](https://github.com/NapNeko/NapCatQQ/blob/859eb530c5801577633c2c3ae871d23586edf281/packages/napcat-onebot/action/go-cqhttp/GetGroupMsgHistory.ts)、[群名片](https://github.com/NapNeko/NapCatQQ/blob/859eb530c5801577633c2c3ae871d23586edf281/packages/napcat-onebot/action/group/SetGroupCard.ts)、[点赞](https://github.com/NapNeko/NapCatQQ/blob/859eb530c5801577633c2c3ae871d23586edf281/packages/napcat-onebot/action/user/SendLike.ts) 和 [禁言](https://github.com/NapNeko/NapCatQQ/blob/859eb530c5801577633c2c3ae871d23586edf281/packages/napcat-onebot/action/group/SetGroupBan.ts) 没有此前 Harness 添加的相应硬上限；去掉本地限制不代表平台承诺任意长度或数量。

## 独立部署配置差异

旧配置不能直接交给新镜像启动。部署前应只读核对原文件，取得逐项授权后原地调整，不从示例覆盖。

| 字段 | 处理 |
| --- | --- |
| `runtime.tool_result_char_limit` | 必须删除；其功能已移除，无兼容忽略分支。 |
| `napcat.event_queue_size` | 新增可选；省略采用原来的 128。 |
| `runtime.max_retained_sessions` | 新增可选；省略采用原来的 100。 |
| `runtime.max_retained_bytes` | 新增可选；省略采用原来的 268435456。 |
| `runtime.config_text_max_bytes` | 新增可选；省略采用原来的 2000000。 |
| `sandbox.transfer_max_bytes` | 新增可选；省略采用原来的 50000000。 |
| `sandbox.max_pending_operations` | 新增可选；省略允许最多 32 项操作在内存中等待。 |
| `mcp.<服务>.effect_tools` | 新增可选，默认空；用于覆盖不准确的只读注解。 |
| egress 环境变量 | Compose 提供 `HARNESS_EGRESS_PORTS=80,443`、`HARNESS_EGRESS_IDLE_TIMEOUT=180`、`HARNESS_EGRESS_CONNECTIONS=32` 默认值；改变端口等取值须另行授权。 |
| 其他业务与连接字段 | 保持原值，包括模型、群配置、人格、知识库、密钥与路径。 |

新镜像还改变了无配置字段的运行行为，例如只读注解分类、分页、排队和失败恢复；这些变化及新字段应随同一完整应用镜像发布，runner/egress 使用同一应用版本。测试过程不修改独立部署配置。
